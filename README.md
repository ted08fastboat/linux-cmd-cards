# 命令卡 · 像背单词一样背 Linux 命令

一个单文件的记忆工具，把 113 个 Linux / RHCSA 常用命令做成卡片：翻卡看释义、听完读音再评价，答不上来的过一会儿还会再来找你。

## 玩法

1. 卡片正面只有命令名（比如 `lvextend`），先自己回想它是干什么的
2. 点卡片（或按空格）翻面，看释义、语法、例子和易错点
3. 三档评价：
   - **不认识** → 这张 5 分钟后还会出现在本轮里
   - **模糊** → 半小时后再来
   - **认识** → 按记忆曲线往后推：1 天 → 3 天 → 7 天 → 21 天
4. 每天 15 张新卡，学完自动停下

评价决定下次什么时候出现，所以「认识」点得太随意，以后会被反复折磨。

## 四种模式

| 模式 | 干什么 |
| --- | --- |
| **学习** | 翻卡看释义，三档评价（不认识 / 模糊 / 认识）驱动复习时间 |
| **测验** | 四选一，10 题一轮。单数题「看命令选意思」，双数题「看意思选命令」—— 反向题更难，能逼你真正记住命令名 |
| **打字** | 只给中文释义，凭记忆把命令敲出来。给首字母和长度提示，敲错立刻显示正确答案和语法 |
| **统计** | 已学 / 已掌握 / 待复习 / 连续天数、分类进度、错题本 |

答错的题（测验或打字）会自动进**错题本**，统计页可以一键「练这些错题」。

## 快捷键

| 键 | 作用 |
| --- | --- |
| `空格` | 翻面 |
| `1` `2` `3` | 学习模式：不认识 / 模糊 / 认识 |
| `1`–`4` | 测验模式：选答案 |
| `Enter` | 下一题 / 提交打字 |
| `R` | 朗读命令 |
| `S` | 切回学习 |

## 功能

- **四种模式** —— 学习 / 测验 / 打字 / 统计，都汇入同一套记忆进度
- **听读音** —— 用系统自带的语音合成读命令名，边听边记发音
- **到点复习** —— 每张卡有自己的复习时间，到期才出现，没到期的不会浪费你时间
- **反向选择题** —— 不只认命令，还要能从意思反推出命令名
- **打字拼写** —— 首字母 + 字数提示，逼你把命令真的敲出来
- **错题本** —— 答错的自动收集，可以单独拎出来练
- **分类筛选** —— 文件 / 文本 / 权限 / 用户 / 系统 / 软件 / 存储 / 网络 / 安全 / 时间
- **同类联想** —— 卡片背面会列出同分类的其他命令，方便成串记
- **熟练度** —— 每张卡 5 格熟练度，靠反复答对累积
- **连续打卡** —— 记录连续学习天数
- **进度全部存在本地** —— 不需要账号，关掉浏览器再打开接着学

## 词库

113 个命令，覆盖 RHCSA（EX200 / RHEL 10）考点：

| 分类 | 数量 | 举例 |
| --- | --- | --- |
| 文件 | 18 | `find` `ln` `du` `tar` |
| 文本 | 16 | `grep` `sed` `awk` `xargs` |
| 权限 | 9 | `chmod` `setfacl` `sudo` `visudo` |
| 用户 | 9 | `useradd` `chage` `gpasswd` |
| 系统 | 13 | `systemctl` `journalctl` `dnf` `rpm` |
| 软件 | 3 | `dnf` `rpm` `flatpak` |
| 存储 | 18 | `lvextend` `mkfs.xfs` `mount` `swapon` |
| 网络 | 12 | `nmcli` `ss` `firewall-cmd` `rsync` |
| 安全 | 9 | `semanage` `restorecon` `setsebool` |
| 时间 | 6 | `crontab` `at` `timedatectl` |

每条都带语法、真实例子和一句易错提醒 —— 比如 `lvextend` 不加 `-r` 只扩了卷、文件系统不会跟着扩。

## 使用

直接用浏览器打开 `index.html`，不用装任何东西。

进度存在浏览器的 localStorage 里，换浏览器或清缓存会丢。统计页有「重置全部进度」。
